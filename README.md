

# 📘 Mulyankan – Student Evaluation System

Mulyankan is a **C++ and Qt-based desktop application** with **SQLite database support**, designed to centralize student evaluation and academic management. It enables seamless interaction between **students** and **teachers**, improving communication, accountability, and performance tracking in an academic setting.

---

## 🚀 Features

### 👨‍🎓 Student Features

* Secure login & registration
* View attendance
* Submit assignments
* Check scores & grades
* Manage personal tasks
* Update profile
* Contact faculty

### 👨‍🏫 Teacher Features

* Take and manage student attendance
* Assign and grade assignments
* Add, update, or delete student records
* View student details and performance
* Provide scores and evaluations
* Contact students

---

## 🛠️ Tech Stack

* **Language**: C++20
* **Framework**: Qt 6.8.2 (GUI)
* **Database**: SQLite3
* **Architecture**: MVC (Model–View–Controller)

---

## 💻 System Requirements

**Software:**

* Qt 6.8.2
* SQLite3
* C++20 compiler

**Hardware (Recommended):**

* CPU: Intel i7 (or equivalent)
* RAM: 8–16 GB
* Storage: 1 TB SSD
* OS: Windows / Linux

---

## 📂 Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/suvam452/mulyankan.git
   cd mulyankan
   ```

2. Open the project in **Qt Creator**.

3. Build the project with CMake/QMake.

4. Run the application.
